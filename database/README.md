# LibraSys database foundation

This directory contains the MySQL 8.x/InnoDB foundation for the LibraSys course project.

## Setup

1. Install MySQL 8.x with a local development instance.
2. Run `01_schema.sql`.
3. Run `02_seed.sql`.
4. Replace the placeholder demo password hashes in the seed file with hashes generated by the ASP.NET 8 password hasher, then run the relevant inserts.
5. Review and adapt the local secrets in `03_security.sql`; do not commit real passwords or keys.
6. Run the demonstration files individually:
   - `04_transactions.sql`
   - `05_encryption.sql`
   - `06_query_optimization.sql`

The security file requires an administrator account. The API account is intentionally not granted role-management, grant-option, file, or global administrative privileges. Application RBAC in the `roles`, `permissions`, and `role_permissions` tables is separate from MySQL account privileges.

## Demonstration evidence

Record the SQL, expected result, and observed result for:

- Borrow/return atomicity and rollback
- Two-session row-lock/concurrency behavior
- Encrypted ciphertext versus decrypted local demonstration value
- Role grants, revokes, view-only reporting access, and denied operations
- `EXPLAIN`/`EXPLAIN ANALYZE` before and after index/query changes

The scripts intentionally avoid real credentials and production key material. A live MySQL server is required for runtime validation.
